# The importer is MIT licensed

`LICENSE` is MIT. It replaces the all-rights-reserved file this repository was generated with,
which the Organisation seeds into every new repository as the written form of *no licence has been
chosen yet* — and which says, in its own closing paragraph, that a repository meant to be open
replaces it wholesale and records why here. This is that record.

## Why a licence at all, this early

Nobody but the author runs this yet. The case for waiting is real: an unlicensed public repository
is readable, the decision stays open, and withholding rights is the reversible direction while
granting them is not.

It loses on what this repository is. A dashboard is *read*; an importer is *run*. This one exists
to be pointed at someone's own NTULearn account and their own Drive folders, and it is public
specifically so that anyone who wants it while it is still being built can have it. Source-available
gives them the right to look at how it works and no right to use it, which is not the offer being
made. Publishing it without a licence would have meant advertising a tool that nobody may legally
run.

So the choice is not *now versus later* but *coherent versus not*. The permission was the reason to
publish; the licence is that permission written where a user can find it rather than inferred from
the absence of one.

## Why MIT rather than the alternatives

- **Apache-2.0** does everything MIT does and adds an express patent grant and a NOTICE mechanism.
  Both are protections for a contributor base and a patent position, and this repository has
  neither. The cost is a licence most readers of a small tool will not finish, in exchange for
  clauses that would not fire.
- **GPL-3.0** would require derivatives to stay open. That is a claim on what other people build,
  and there is nothing here worth making that claim about — a downloader for one university's
  learning platform is not a commons to defend. It would also make the tool unusable inside anyone
  else's closed coursework tooling, which is a plausible way for it to be useful.
- **Unlicense / public domain** discards the warranty disclaimer, and this software drives an
  authenticated session against a university's systems. The disclaimer is the one clause here that
  is doing real work.
- **MIT** grants use, modification and redistribution in a paragraph, keeps the warranty
  disclaimer, and is recognised by GitHub's `licensee` — so the sidebar states the position instead
  of leaving a reader to infer it, which was the seeded file's entire complaint about silence.

## What the licence does not grant

MIT covers this code. It says nothing about **what the code fetches**: course material belongs to
its authors and to NTU, and access to it is governed by the account being used and the university's
terms, not by this file. The tool reads only what the logged-in student can already see, and
mirroring it does not enlarge the rights that student has to it.

That distinction is worth stating here because the licence is the file a user checks, and the
question it *looks* like it answers — "may I do what I like with what this downloads?" — is not one
it answers at all.

## Consequences

- **This is not reversible.** Any commit published under MIT stays available under MIT to anyone
  who already has it; a later relicence binds only what comes after. That is the accepted cost, and
  it is why the decision gets a record rather than a commit message.
- **Contributions arrive under MIT.** Inbound-equals-outbound is the default reading, and with the
  repository public and its issues on, that is the term a contributor is agreeing to.
- **The Organisation's seeded default is now diverged from, deliberately.** A reader comparing this
  repository with the other public one will find it licensed where the other is not; the reason is
  in this file, and the Organisation's side of it is in the management hub.
- **`LICENSE` is no longer a seeded file for this repository.** It is owned here, so the
  Organisation's refresh of seeded documents leaves it alone — which is the mechanism working, not
  drift.

## Revisit when

- **Someone contributes something substantial.** A contributor base is the condition that makes
  Apache-2.0's patent grant worth its length, and the point at which inbound terms should be stated
  rather than assumed.
- **Transcription ships.** It would add model or service dependencies whose own licences may
  constrain the combined work, and this record should be checked against them rather than presumed
  compatible.
- **NTU objects to the tool existing.** That is not a licensing question, but it is the event most
  likely to change what this repository is for, and the licence is downstream of that.
