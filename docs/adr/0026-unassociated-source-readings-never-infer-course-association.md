# Unassociated source readings never infer course association

An explicit standalone formatting route may add deterministic reading editions for valid retained
raw sources within the configured Media store whose metadata sibling is positively absent. These
editions always remain review-only, with course association unverified by the edition. Metadata absence
is not proof of no association elsewhere. A filename, title or apparent lecture wording supplies no
course authority. The existing historical, recovery and catalogue association boundaries stand.

Source presentation is useful before placement can be proved. Requiring a guessed course to make
retained text readable would convert convenience into an invented authority. Original raw bytes and
supported timestamps remain retained; mandatory native and lexical guards apply, with mathematics,
uncertain wording and suspicious repetition unchanged. Flags remain visible and prevent any readiness
claim. This is an explicit review surface, separate from ordinary production paragraphs and source
recovery; ADR-0017 and ADR-0020 retain their source-preservation and review rules.

## Consequences

Each reading has immutable source SHA/path provenance and an opaque identity. An unchanged repeat
skips identical bytes; edited or different occupied outputs refuse. A plan-specific review index does
not become a course index or preferred catalogue edition. Source correction, media ownership/readiness,
upstream completeness and acoustic verification stay unclaimed. Metadata-present sources are accounted
for but excluded for the existing course routes; invalid sources produce no reading edition.

Root/profile/runtime exclusions precede content reads. Current source, metadata-absence and descriptor/
parent proofs remain mandatory, with reserve and apply-lock protections. Unknown I/O or descriptor
settlement retains admission containment; deadlines claim observation bounds, not physical cancellation.
No command automatically attaches evidence, overwrites originals/user edits or clears source review.

## Revisit when

A positive independent association can place a retained source under an existing course route without
changing its bytes or suppressing uncertainty. Differing inventory counts require explicit evidence
reconciliation, never automatic attachment by this reading route.
