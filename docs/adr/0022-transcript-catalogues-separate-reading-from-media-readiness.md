# Transcript catalogues separate reading from media readiness

An explicit local catalogue links a stable course index to verified immutable transcript editions.
A preferred edition is a reading choice supported by current source ownership and retained production
proof, never the newest file. Unique eligible recovered candidates precede unique eligible current-source
paragraphs; equivalent digests group, and distinct candidates require an explicit pinned selection.
Unknown, edited, stale or ambiguous evidence remains review. Source-review flags exclude paragraph
preference. Independent candidate verification does not clear canonical source review or queue readiness.
Historical unknown timing stays labelled; recovered unknown timing cannot qualify. Acoustic accuracy
remains unrun. ADR-0017, ADR-0020 and ADR-0021's preservation and source-review boundaries stand.

Run-specific indexes make retained editions hard to find. Updating canonical originals or choosing
by modification time would hide annotations and confuse presentation with recognition quality.
Instead, an Owner-authorized publication updates only an index whose current bytes match positive
producer evidence, retaining its beforeimage, immutable snapshot and durable journal. Unknown or
student-edited index/edition evidence refuses. This is a separate operation; ordinary sync never
publishes, prunes or renames transcript content. The index is operational navigation rather than a
licence to replace transcripts.

## Consequences

Generation candidate/native/assessment evidence remains immutable. Catalogue admission independently
rechecks current per-recording queue claim, raw/media/state and metadata/original or typed absence.
An unrelated queue update therefore need not permanently stale a retained candidate. Recovery run and
publication keep their stricter generation-time whole-manifest pins. A catalogue publication plan
pins the entire inspected current inventory, refusing changes after planning. Current media is fully
hashed at admission and final publication; bounded nofollow descriptor-bound device/inode/size/mtime/ctime
checks guard each intervening step without repeatedly hashing large recordings. Changed bytes, replaced
identities or links refuse; this does not establish universal external-edit exclusion. Replan explicitly when
inputs progress. Retained artifacts must remain accessible for independent candidate verification.

Each recognized recording exposes reading verification, canonical source review and media verdict separately.
All queue appearances retain explicit disposition and classification evidence: unresolved review and
positively classified non-recordings have separate counts/sections instead of masquerading as lectures.
Legacy queue paths keep the queue reader's fallback semantics and attempted missing-path pins. Configured
profile boundaries use only physical metadata, including an absent leaf's existing ancestor, and recheck
logical bindings before inventory; overlapping course/media roots refuse before contents are read.
Explicit manifest, selection and derived plan-receipt paths are excluded from both logical and physical
profile boundaries using metadata before any content access and rechecked immediately before reads/writes.
A dangling alias refuses; an ordinary sibling outside the profile remains a valid private plan location.
Immutable history and managed promotions each check the actual destination boundary and byte budget,
independently of the media admission reserve. Historical paragraph media links remain unproven unless
current recovery ownership supplies positive media evidence; text proofs cannot invent that ownership.
Unassociated retained evidence is counted and reported without guessed course placement. Inspection
reads only bounded configured local roots; it cannot establish unseen upstream recording completeness.
Its stdout is private metadata, while actions emit bounded structured evidence without source text.
Implementation/checks use offline fixtures; later Owner publication is a separate authorized phase.

A private plan receipt pins planned bytes. Managed index transitions journal old/new hashes and retain
exclusive history before promotion; an interrupted transition resumes only that unchanged plan and
accepted producer bytes. Parent identities and nofollow reads are rechecked before each promotion.
A rename after bounded checks cannot universally compare-and-swap against a noncooperating external
editor. Refused or uncertain cleanup retains evidence rather than deleting a replacement or claiming
readiness. No model, browser, network, setup installation or queue/status mutation is involved.

## Revisit when

A stronger independent acoustic assessment or explicit canonical source-promotion workflow exists.
Neither is inferred from readable paragraphs or a catalogue preference.
