# Support

**Open an issue on the repository you have a question about.** That is the whole channel, and it
is deliberate: an answer in an issue is searchable by the next person who asks, an answer in a
mailbox is not.

Use the **Bug** form if something is behaving wrongly, and the **Task** form if you want
something to work differently. If you only want to know how something is meant to work, a Task
with the question in the summary is fine — it will be triaged as a question, not as a feature.

Before you file, read the repository's `CONTEXT.md` if it has one. It is the glossary, and most
confusion here is vocabulary rather than behaviour.

Two things support is **not**:

- **Not an SLA.** One maintainer, best effort. See [CONTRIBUTING](CONTRIBUTING.md) for how an
  issue moves once it is filed.
- **Not for vulnerabilities.** Those go to security@jeromegroup.org, privately —
  [SECURITY](SECURITY.md).
